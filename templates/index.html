Documentation

Pipeline

XRefactor combines a rule-based code-smell detector, a GNN refactoring-type classifier, a deterministic AST refactoring engine with javac verification, a neural fallback generator, and a template-based explanation layer.

Reading the two groups apart

  • Run views describe one analysed corpus. All figures come from one saved run.
  • Evidence views describe the models, from an offline evaluation on a different corpus and date.

Repository docs: ARCHITECTURE.md, DEVELOPMENT.md (known limitations), TESTING.md.

API Reference

Base URL: /api

  • GET /health — health check
  • GET /config — effective server-side configuration
  • GET /pipeline/stages — stage descriptions
  • GET /pipeline/status — whether a run is in progress
  • POST /pipeline/run — run the full pipeline (synchronous)
  • POST /pipeline/stage/<name> — cpg_construction or gnn_reasoning only
  • GET /runs — list saved runs, newest first
  • GET /runs/<id> — one saved run (latest accepted)
  • GET /runs/<id>/evidence — stage-4 evidence cards for that run
  • GET /benchmarks — offline evaluation, model metrics, mining dataset, taxonomy
  • GET /supported-languages, GET /gnn-models — static metadata
