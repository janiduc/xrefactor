Documentation

📖 XRefactor Pipeline

XRefactor is an AI-driven framework for cross-file code refactoring with explainable AI.

Key Features:

  • Multi-stage Pipeline: CPG → GNN → Transformer → XAI
  • Multiple Languages: Java, Python, and more
  • GNN Models: GAT, GCN, GraphSAGE architectures
  • Explainability: Causal inference & evidence cards
  • GPU Support: CUDA acceleration for faster processing

Architecture Overview:

See ARCHITECTURE.md for detailed component documentation.

Development Guide:

See DEVELOPMENT.md for development setup and workflows.

🔗 API Reference

Base URL: http://localhost:5000/api

  • GET /health - Health check
  • GET /pipeline/stages - Get pipeline stages
  • POST /pipeline/run - Run full pipeline
  • POST /pipeline/stage/<name> - Run specific stage
  • GET /supported-languages - Supported languages
  • GET /gnn-models - Available GNN models
